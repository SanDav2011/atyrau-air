About the project

“Kazakhstan Air” is an open information project

Why this project

This is a non-profit project. It helps residents understand air quality: for example, it shows where the hydrogen sulfide smell in Atyrau comes from and how wind direction and speed affect it.

The city map shows each station’s readings, the wind and a comparison with limit values. The page about gases explains what each substance is, how it is measured and how it affects health.

Authors

Where the data comes from

  • Kazhydromet — station measurements (ecodata.kz, tabigat.gov.kz)
  • Open-Meteo — wind, temperature, cloud cover
  • OpenStreetMap — borders of regions and cities, locations of industrial facilities
  • Order No. ҚР ДСМ-70 — limit values

Important notice

This is not an official warning. The sources and colours shown are a model estimate; official data on actual pollution comes from the monitoring stations themselves. Nor is this medical advice: if you feel worse, call 103 or see a doctor.
