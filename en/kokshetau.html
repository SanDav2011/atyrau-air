    📘 Methodology and notes

    Click a section to open it.

    1. Data

    Stations — the Kazhydromet map (ecodata.kz), hourly. Wind, solar radiation and cloud cover — Open-Meteo, city centre (53.283, 69.4256). Data collection for Kokshetau began on 21 October 2026 — the history is still short.

    2. Main issue

    SO2 was chosen as the main substance (a project decision: most stations measure it); other substances are in the substance list above.

    3. Limit values

    Order No. ҚР ДСМ-70 (02.08.2022), Annex 1 — maximum one-time limit. Stations report hourly values, so the comparison is approximate.

    4. Data quality

    If one value stays the same for 6 hours in a row, it is marked as “stuck” (⚠) and excluded from the analysis.

    5. Source identification There is no list of pollution sources for Kokshetau yet. The wind rose and “persistently high stations” work.
